## 使用

```powershell
.\.venv\Scripts\python.exe run.py
```

打开工程或离线示例 → **任务与算法** → 打开所需属性窗口 → **恢复参数默认** →
查看待应用状态 → **应用并关闭**。取消、Esc 或关闭窗口均放弃草稿；计算和保存仍需分别操作。

| 窗口 | 恢复范围 | 保留内容 |
|---|---|---|
| 算法与范围 | 本窗口 PID、LQR 参数、力矩上限、控制周期 | 算法及执行机构选择、阶段范围、其他执行机构参数 |
| 场景与气动 | 本窗口显示的场景与气动数值 | 装配、发动机、未展示的输出周期和气动适用域等配置 |
| 模拟传感器 | 本窗口显示的周期、延迟、噪声与偏置 | 安装旋转、未展示的饱和与失联条件 |
| 执行机构 | 当前执行机构窗口显示的响应与物理参数 | 执行机构类型、安装位置、其他执行机构和控制参数 |

默认数值直接取自 `Scenario`、`SensorConfig`、`ControlConfig`，未新增第二套默认值或更改科学内核。
恢复只改私有草稿，不重建零件、设计或运行身份，不替换导入发动机证据。
零件质量、尺寸和发动机试验值没有可信的通用默认，因此不提供会覆盖它们的全局重置。
气动数值改变后，当前来源改为模型已有的“工程近似”声明；仅改重力等场景值时保留气动来源。
导入缺项不会因恢复默认而自动通过审核。

属性窗固定显示“待应用 / 与已应用配置一致 / 输入未完成”和参数偏离默认的数量。
数值输入的提示提供模型默认值；不完整数字不再被标成“均为默认”。
恢复按钮明确禁止成为 Enter 的默认动作；Enter 走输入提交或应用，聚焦按钮后可用空格主动恢复。
任务页补充配置偏离摘要，运行中明确显示后续编辑只影响下一次运行。
向量、四元数改用具名分量的两列输入，长标签换行；底部动作不随表单滚走。
