# TreeDiagram GUI 约定

保留 2026-10-13 GUI 外壳的深蓝标题/侧栏、文件菜单、中文字体和浅深主题。2026-11-01 用户明确的六自由度产品任务取代历史“定位待定”描述。

1. 标题固定 TreeDiagram，版本唯一来源为包 `__version__`。概览、模型、任务与算法、结果为真实工作区。
2. 模型采用对象树、可旋转结构预览、当前对象属性；不同时铺开所有表单。原生图形由实际零件几何绘制，轨迹由已完成运行绘制。
3. 功能实例只配置一次，范围包括结束阶段；阶段胶囊是逻辑范围，不暗示实际持续秒数。当前仅支持 powered/coast/descent 固定模拟阶段，不冒充任意 SCG mission 图。
4. Apply/Cancel/Esc 使用草稿；修改、导入失败、运行取消保留正式状态。文件操作保留原有冲突检测和未保存提示。
5. 线程执行仿真，GUI只读取锁保护的进度/结果；关闭运行窗口先请求取消。图表注明单位与来源，历史结果绑定原快照。
6. 当前仅有简体中文；不显示无效语言开关。浅深主题即时生效，工程脏状态不因主题或导航改变。
7. 920×620 为紧凑窗口；表单放可滚动区域，确认按钮固定在底部；高 DPI 使用 Qt 原生缩放。截图注明 offscreen/desktop 与缩放环境。
8. 参数包/ABI/哈希收在诊断或文件说明中。实际不可部署能力明示，不通过灰掉错误或换标签伪装接通。
