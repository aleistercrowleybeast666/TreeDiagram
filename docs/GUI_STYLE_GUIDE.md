# TreeDiagram GUI 外壳规范

参照 2026-10-13 本机 SilverStar_FLP 的实际界面实现与规范：

- `../SilverStar_FLP/src/silverstar_flp/ui/main_window.py` 的 `_Ui_Build`；
- `../SilverStar_FLP/src/silverstar_flp/ui/theme.py`；
- `../SilverStar_FLP/docs/GUI_STYLE_GUIDE.md`；
- `../SilverStar_FLP/docs/CXYL_Python_GUI_STYLE_GUIDE.md`。

以上路径相对于 TreeDiagram 根目录。这里只借鉴外观与交互，不复制或依赖 FLP 的日志、算法、插件、数据协议或业务页面。

1. 原生窗口标题固定为 `TreeDiagram`。顶栏显示产品、版本、预览阶段、当前工程；右侧显示简体中文和主题。版本唯一来源是包内 `__version__`。
2. 深蓝顶栏与 190 px 左侧导航；浅色使用 `#123A78`、强调色 `#2F6FED`，深色使用 `#0B2447`、强调色 `#3B82F6`。不支持原生标题着色时保留系统窗口框架。
3. 文件菜单集中放新建、打开、保存、另存为、退出；提供常用快捷键，不增加重复工具栏。只有实际实现的操作可以成为可点击功能。
4. 工程概览编辑名称和备注。数据、运行配置、结果只作为暂定工作区，持续显示“占位/待确定/未启用”，不能暗示已完成计算或预先决定业务方向。
5. 使用统一的微软雅黑 UI 字体、浅/深色控件、表头、菜单及下拉列表。概览与占位页支持垂直滚动，在 920×620 到 1440×900 范围不以缩小字体掩盖布局问题。
6. 当前仅实现简体中文；不显示无效的英语切换项。主题切换即时生效，本轮不增加用户配置持久化、图表、3D 或导出功能。
7. 工程路径只在内容/提示中显示；未保存更改有可见标记。新建/打开/退出前提供保存、放弃、取消；文件选择取消不落盘。
8. 状态栏提供可读状态。当前没有任务，故不显示空转的进度条或取消任务按钮。
